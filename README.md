## Preview locally
Open `index.html` in your web browser. The castle image and Google Fonts need an internet connection.

## Host on GitHub Pages
1. Create a GitHub repository, e.g. `aara-princess-birthday`.
2. Upload `index.html`, `style.css`, `script.js` and optionally this README to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then press **Save**.
6. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/aara-princess-birthday/`.

No Vite base path or build command is required for this plain HTML version.

## Customise
- Change the birthday details in `index.html`.
- The Add to Calendar event is in `script.js`. It currently uses 6:00 PM–9:00 PM.
- Replace the remote castle image URL in `index.html` with your own princess/castle image if desired.
